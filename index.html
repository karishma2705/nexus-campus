Clear, local data storage

Know where your details live.

Student records stay with the backend project folder. The app never exposes the Excel file as a public download.

01 · SIGN-IN

Session and OTP state

data/nexus.sqlite stores session hashes, OTP challenge hashes, expiry and verification status. There is no password-based student login in this prototype.

02 · STUDENT PROFILE

SQLite plus Excel

After your selected contact is verified and you consent, your name, contact and academic details are saved to data/student_profiles.xlsx and the SQLite profile table.

03 · ACCESS

Project folder only

The backend blocks these private files from website downloads. The project operator can open the Excel workbook from the server's data folder.
